# Makasete AI 導入ガイド

### スプレッドシートで管理できる Makasete AI サーバー

---

## Makasete AI とは？

AIを活用した、**音声とテキストどちらにも対応**した Makasete AI サーバーです。

スプレッドシートを更新するだけで、AIの知識や性格を即座に変更できる柔軟性が特徴です。

---

## 1. 主な機能

- **柔軟なチャット**: テキストと音声に対応し、柔軟に回答をレスポンス。
- **低遅延ストリーミング**: AIの回答を逐次音声合成。待ち時間を最小化。
- **動的コンテキスト管理**: スプレッドシート（Google Sheets）との連携により、商品情報やFAQをノーコードで更新可能。
- **マルチデバイス対応**: PC、スマホ（iOS/Android）の主要ブラウザで動作。
- **スプレッドシートのAPI化**: スプレッドシートで管理しているデータはAPIで呼び出し可能。
- **多言語対応（i18n）**: 日本語・英語・中国語（簡体字）に対応。ブラウザ言語を自動検出。

---

## 2. どんなことに使えるのか？

- **ECサイトの接客**: 商品選びの相談や、おすすめ商品の提案。
- **カスタマーサポート**: よくある質問（FAQ）への回答。
- **サービス紹介**: 複雑なサービス内容を対話形式で分かりやすく説明。
- **店舗案内**: 営業時間やアクセス情報の提供。
- **スプレッドシートのDB化**: スプレッドシートを商品やFAQを管理するDBとして利用可能。
- **グローバル展開**: 多言語対応により、海外ユーザーへのサポートも可能。

---

## 3. 得られる効果

- **顧客体験（CX）の向上**: テキスト入力の手間を省き、より直感的で温かみのある対話を提供。
- **コンバージョン率の改善**: AIによる適切な商品提案により、購買意欲を促進。
- **運用コストの削減**: スプレッドシートを書き換えるだけで知識ベースを更新できるため、開発者の工数を削減。
- **バックエンド実装の削減**: データの管理と配信機能を提供するため、独自のバックエンド実装が不要。

---

## 4. システム構成

### フロントエンド (Widget)

- Vanilla TypeScript / Web Components
- 音声認識: Web Speech API
- 多言語対応: ブラウザ言語自動検出 / `data-locale` 属性による明示指定

### バックエンド (Server)

- Node.js (Express) / Socket.io
- LLM: Google Gemini API
- TTS: Google Cloud Text-to-Speech or ElevenLabs（デフォルトでは Google TTS）

### インフラ

- Google Cloud Run
- Google Sheets API

---

## 5. スプレッドシートの基本構成

AI の知識ベースとなるスプレッドシートの構成です。

| シート名 | 役割               | 備考                               |
| :------- | :----------------- | :--------------------------------- |
| `prompt` | システムプロンプト | A1 セルに指示を記載（必須）        |
| `(任意)` | 知識ベース         | シート名がそのままカテゴリ名になる |

- `prompt` シートは **A1 セル**の内容のみが使用されます。
- それ以外のシートは、AI が参照する「知識」として扱われます。
- **[サンプルスプレッドシートはこちら](https://docs.google.com/spreadsheets/d/1DYAZ3UM2iZjXRbG04nVTrYvEVNN_9mxzZ44qF6BEiC8/edit?usp=sharing)**

---

## 6. 知識ベース（任意シート）の仕様

自由に追加できる知識ベース用シートの制限と特徴です。

- **カラムの柔軟性**: カラム名や数は自由に変更でき、AI が自動で解釈します。
- **行数制限**: 1 シートあたり先頭 **100 行**まで読み込まれます。
- **列数制限**: カラム（列）は **A から Z まで**が対象です。
- **ヘッダー**: 1 行目は必ず**項目名（ヘッダー）**として扱われます。
